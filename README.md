# Shopx — Web Bán Hàng Đa Danh Mục

> Giao diện xanh chuyên nghiệp · Flask + SQLite · 85+ sản phẩm · Admin đầy đủ

## Cài đặt & Chạy

```bash
cd shopx
pip install -r requirements.txt
python app.py
```

Mở trình duyệt: http://localhost:5000

## Tính năng

### Người dùng
- Đăng ký / Đăng nhập / Quên mật khẩu (câu hỏi bảo mật)
- Trang cá nhân, đổi mật khẩu
- Yêu thích sản phẩm
- Giỏ hàng (thêm / sửa / xóa)
- Thanh toán mô phỏng: COD, thẻ tín dụng, ví điện tử
- Lịch sử đơn hàng + chi tiết
- Đánh giá sao + bình luận

### Tìm kiếm
- Gợi ý realtime (hỗ trợ tiếng Việt có dấu)
- Lọc: danh mục, khoảng giá, sao, sale
- Sắp xếp: phổ biến / mới / giá

### Chatbot
- Trả lời câu hỏi, kể chuyện cười
- Gợi ý sản phẩm theo từ khóa

### Admin (/admin)
- Dashboard + biểu đồ Chart.js
- Quản lý sản phẩm (CRUD + upload ảnh)
- Quản lý tồn kho realtime
- Quản lý đơn hàng + trạng thái
- Flash Sale + đếm ngược
- Thông báo banner / popup
